# Personal Assistant: The Daily Briefing Page

Triage email, calendar and follow-ups into a private, bookmarkable briefing that shows what needs attention and which sources could not be checked.

[Read the full use case on onet.com.au](https://onet.com.au/projects/agent-use-cases/daily-briefing/).
