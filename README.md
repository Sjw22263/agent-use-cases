# Agent Use Cases

Companion templates and worked examples for the [Agent Use Cases on onet.com.au](https://onet.com.au/projects/agent-use-cases/). The website describes the work. These files help you set up a new agent to perform the same function in your environment.

## Quick start

1. Choose a use case below and give that folder’s `agent-template.md` to the AI doing the setup.
2. Give it the [shared setup guide](https://onet.com.au/projects/agent-use-cases/agent-instruction.md) and name the use case. The guide covers Claude, ChatGPT, Hermes Agent and other agentic harnesses.
3. Review its proposed configuration and permissions. Use `worked-example.md` to check the setup with fictional inputs before connecting live accounts or enabling write access.

The examples are illustrative, not reports of live tests. Keep permissions scoped to the role and only enable actions you have approved.

## Use cases

- [Songwriting and Music Development](songwriting-and-music-development/): Refine a songwriter’s draft for metre, cadence and musical direction, then prepare separate Style and Lyrics inputs for a Suno audition.
- [Editorial Research and Draft Review](editorial-research/): Turn an observation into an editorial proposition, check the evidence and decide whether to pursue, narrow or drop the claim.
- [Visual Direction for Images and Short Video](visual-direction/): Turn a brief into copy-ready image and video prompts, with separate settings and checks for the returned renders.
- [Social Platform Promotion](social-platform-promotion/): Prepare a music release, verify the media, stage and schedule it on YouTube, and check playback before promoting it on Facebook.
- [Specialist Research and Public Information](specialist-research/): Trace specialist claims to their sources and adapt what the evidence supports for a website, social post or public reference work.
- [Independent Second Opinions](independent-second-opinions/): Check whether the evidence supports a proposed decision and identify the smallest check that could change the advice.
- [Personal Assistant: The Daily Briefing Page](daily-briefing/): Triage email, calendar and follow-ups into a private, bookmarkable briefing that shows what needs attention and which sources could not be checked.

## System Administration

Start with the [System Administration use case](https://onet.com.au/projects/agent-use-cases/system-administration/), then use the separate [Sysadmin Agent Kit](https://github.com/Sjw22263/sysadmin-agent-kit) for commissioning, staged authority and operational templates. That kit is not duplicated here.
